# 📱 Corso PON: Sviluppo App Mobile (Android & iOS)

Repository personale contenente appunti, esercizi e progetti realizzati durante il **Corso PON per lo sviluppo di applicazioni mobile per Android e iOS**.

---

## 🛠️ Tech Stack & Strumenti

- **Framework:** [React Native](https://reactnative.dev/)
- **Tooling Platform:** [Expo](https://expo.dev/)
- **Linguaggio:** TypeScript (`.tsx`)
- **Ambiente di Esecuzione:** Node.js / Expo Go

---

## 🚀 Setup e Inizializzazione Progetto

### 1. Requisiti
Assicurati di aver installato [Node.js](https://nodejs.org/) sul tuo sistema e l'app **Expo Go** sul tuo dispositivo mobile (iOS o Android) per il testing in tempo reale.

### 2. Creazione di un Nuovo Progetto
Per inizializzare un nuovo progetto React Native con TypeScript tramite Expo, esegui:

```bash
npx create-expo-app@latest <nome_cartella_progetto>
```

### 3. Avvio dell'Ambiente di Sviluppo
Spostati all'interno della cartella del progetto e avvia il server di sviluppo:

```bash
cd <nome_cartella_progetto>
npm start
# oppure
npx expo start
```

Scansiona il codice QR generato nel terminale utilizzando l'app **Expo Go** (su Android) o la **Fotocamera** (su iOS).
